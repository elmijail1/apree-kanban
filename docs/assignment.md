# TEST ASSIGNMENT
## Goal
Create a small task-tracking app with a kanban-style dashboard.

## Compulsory features
- 3 columns: "Новая", "В работе", "Готово"
- To create a task you need to specify a name, a description, and a priority
- You can view, edit, and delete tasks
- Tasks can be moved between columns
- Data must persist between page reloads
- The app must be convenient to use both on desktop and on mobile
- The dashboard must have states for: loading, errors, and no data
- The data must be stored in a database and handled through an API

## Tech stack
- TypeScript
- React / Next.js
- Material UI
- NestJS
- PostgreSQL

## What a finished task must have
- A repo and guidelines for running the app
- DB migrations
- A few checks of the core logic (tests)
- Brief description of solutions, limitations, and time spent
